## 🔬 Research Focus

- **LLM Post-training** — SFT, preference optimization, PPO-style learning, critic training, and reward shaping.
- **Coding Agents** — long-horizon SWE tasks, executable repositories, test generation, replay pipelines, and on-policy distillation.
- **Tool-use Agents** — multi-turn environments, state-guided data synthesis, argument provenance, online interaction, and verification.
- **Evaluation & RSI** — executable-environment evaluation, hard-case discovery, capability benchmarks, and recursive improvement loops.

```text
Data Synthesis  →  Post-training  →  Agent Interaction  →  Evaluation  →  Improvement
```
